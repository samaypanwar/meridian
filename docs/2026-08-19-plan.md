# Meridian MVP Implementation Plan

> **For agentic workers:** Use TDD, one task at a time, commit after each task.
> Steps use checkbox (`- [ ]`) syntax. This plan favors deep TDD detail on the
> load-bearing pure logic (priority, scheduler) and lighter task-level detail on
> commodity I/O and UI.

**Goal:** Build the Meridian MVP — a goal-aware reading queue with capture and
spaced review.

**Architecture:** FastAPI backend + React frontend. Markdown (vault + `goals.md`)
is the source of truth; SQLite is the derived operational store; binaries live in
`data/documents/`. LLM via OpenRouter; embeddings local. See
[architecture](2026-08-19-architecture.md).

**Tech Stack:** Python 3.14, Poetry, FastAPI, `trafilatura`, `pymupdf`,
`youtube-transcript-api`, `sqlite-vec`, `sentence-transformers`, React + Vite.

## Global Constraints

- Python `^3.14`, managed with Poetry only (no global pip, no ad-hoc venv).
- All chat model calls go through `llm/client.py`; provider/model from config.
- Embeddings are local; never assume an OpenRouter embeddings endpoint.
- Markdown is source of truth; anything in SQLite must be rebuildable from it,
  except `reviews` scheduling and `queue_overrides`.
- Banned words in generated objective prose: understand, know, learn about,
  grasp, appreciate.
- Every task ends with passing tests and a commit.

## Milestone M3 — Scoring + priority

### Task M3.1: Priority math (pure, TDD-first)
**Files:**
- Create: `src/meridian/scoring/priority.py`
- Test: `tests/scoring/test_priority.py`

**Interfaces:**
- Produces: `priority.compute(relevance, urgency, effort) -> float`;
  `priority.decay(urgency0, lam, age_days) -> float`.

- [ ] Write failing test:

```python
from meridian.scoring import priority

def test_priority_is_value_per_effort_scaled_by_urgency():
    assert priority.compute(relevance=8, urgency=5, effort=2) == 20.0

def test_priority_rejects_zero_effort():
    import pytest
    with pytest.raises(ValueError):
        priority.compute(relevance=8, urgency=5, effort=0)

def test_evergreen_urgency_does_not_decay():
    assert priority.decay(urgency0=5, lam=0.0, age_days=30) == 5.0

def test_timely_urgency_decays_monotonically():
    assert priority.decay(5, 0.1, 10) < priority.decay(5, 0.1, 1)
```

- [ ] Run tests, confirm failure.
- [ ] Implement:

```python
import math

def compute(relevance: float, urgency: float, effort: float) -> float:
    if effort <= 0:
        raise ValueError("effort must be > 0")
    return relevance * urgency / effort

def decay(urgency0: float, lam: float, age_days: float) -> float:
    return urgency0 * math.exp(-lam * age_days)
```

- [ ] Run tests, confirm pass.
- [ ] Commit `feat: priority + urgency decay`.
